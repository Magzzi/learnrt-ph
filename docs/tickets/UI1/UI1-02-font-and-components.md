# UI1-02: Serif headings and shared components

Spec: [UI1](../../specs/UI1.md) · Depends on: UI1-01, UI1-D1

## What
Bundle the heading font (expo-font, waits on splash); `ScreenHeader` (serif title, subtitle, settings button to About), `Card`, `PrimaryButton`, `SecondaryButton`, `Chip`, toggle row, Line leg icon.

## Acceptance criteria
- Components render in both themes; the font shows offline on first launch.
