# M1-10: Device demo checklist

Spec: [M1](../../specs/M1.md) · Depends on: M1-01 to M1-09

## What
`docs/tickets/M1/demo-checklist.md`: the steps from each ticket's Demo, run on a device in airplane mode, in English and in Filipino, at 1.3× font scale on a small screen. It is run by the owner on Expo Go, or by Claude on an Android emulator if one is installed. Each step is recorded as pass or fail.

## Acceptance criteria
- Every step has a recorded result; failures become fix tickets before M1 closes.
