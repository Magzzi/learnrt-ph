# M1-04: English and Filipino

Spec: [M1](../../specs/M1.md) · Depends on: M1-03

## What
i18next and expo-localization. `en` and `fil` resources; the default follows the device language (Filipino for `fil` or `tl`, English otherwise); a manual switch that is remembered. The tab labels and the Unverified badge use it. Filipino copy is drafted by Claude, and every Filipino string is marked "needs review" in the translation file.

## Acceptance criteria
- A test fails if a key exists in one language but not the other.
- A test checks the language choice: `fil-PH` and `tl` → Filipino, `ja-JP` → English.
- Station and Line names are never passed through translation.
- A test fails if any Filipino string lacks the "needs review" marker, until the review is recorded.

## Demo
