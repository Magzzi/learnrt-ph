# M2-10: GPS playback and device demo

Spec: [M2](../../specs/M2.md) · Depends on: M2-08, M2-09

## What
A script (`apps/mobile/scripts/`) that feeds Station positions along a route into the emulator's location test provider at a set pace. Run the M2 demo checklist: one single-Line route and one route with a Transfer, screen locked; airplane mode; Filipino; manual fallback; kill and resume.
